My First Alarm

A few months ago, during my last semester, I challenged myself to build my own smart alarm clock using an ESP32.

The original goal was to create a device capable of playing music from a microSD card, displaying the weather, showing the time and date, and eventually supporting voice recognition. After writing most of the software, I accidentally burned my microSD adapter while soldering it, and the project came to a stop.

2 days ago, I realized that whenever I wake up to music instead of a standard alarm, my entire day feels different. That was enough motivation to revisit the project.

    This time, I challenged myself to build it using only the components I already had. I simplified the design and focused on the features that mattered most:
  1. An Internet radio that automatically starts playing at alarm time.
  2. Time, date, and weather display.
  3. embedded web server that lets me configure the alarm directly from my phone.
  4. I originally wanted to integrate Spotify, but the free version doesn't provide the access needed to stream directly to the ESP32, so I switched to an Internet radio stream instead.
  5. Another challenge quickly appeared: I didn't have a case or access to a 3D printer. My solution? Build a custom enclosure using #LEGO bricks I found at home. It's far from the final design, but it works.

    The biggest lessons came from debugging:

  • Fixing unstable I2C communication with the LCD.
  • Optimizing MicroPython so the web server stayed responsive while handling physical button inputs.
  • Solving RAM limitations during I2S audio streaming.
  • Finding direct MP3 streams instead of parsing HTML pages.

    • This project has taught me a lot about embedded systems, low-level programming, hardware debugging, and even improved my soldering skills. I thought it would take me 1 day maximum, but It's still a work in progress, but every challenge solved brings me one step closer to the device I originally imagined.

    I'm always happy to connect with other ESP32 and MicroPython enthusiasts and hear about the challenges you've encountered.
